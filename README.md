## 🚀 Deployment

This project is configured for automatic deployment via GitHub to Vercel:

1. **Push to GitHub**: Any push to main branch triggers deployment
2. **Vercel Integration**: Automatically builds and deploys
3. **Custom Domain**: Can be configured in Vercel dashboard

### Environment Variables

Set these in Vercel dashboard if needed:
- `SITE_NAME`: Website name
- `COMPANY_EMAIL`: Contact email
- `COMPANY_PHONE`: Contact phone
